# 安装装备后的取景修复

## 已复现的问题

1. Car6安装凿式犁后，镜头距离从5.2增至8.321679。旧逻辑使用旋转后的世界包围盒外接球，产生过大的空白边距。
2. Car7从拖车切换到普通机具，仍保持90度广角和拖车展示旋转，没有恢复原65度视野。
3. Car3安装机械臂或RTK后，旧回调将镜头从35强制拉到50。Car0使用另一种相机控制器，实测其32的镜头距离不受该旧回调影响。

## 修复与边界

- 车辆和机具的网格、真实尺寸、外参、仿真碰撞及算法参数均未修改。
- 普通机具按稳定的车体局部网格与实际相机视锥计算必要的取景距离，安装动画不参与取景尺寸计算。
- 拖车退出状态首先恢复原车身位置、旋转、比例和相机视野，再为当前机具取景。
- 移除安装机械臂/RTK时强制跳到远距离视角的旧回调。

Car6凿式犁修复后的必要视距为7.212902，所有网格包围盒角点均在画面内。较大的真实机具仍可能需要拉远，不能以裁掉机具换取固定5.2的距离；本次解决的是多余的拉远、广角残留和强制跳变。

初期固定5.2视距的试验断言过于严格，不作为最终验收条件；最终回归检查真实比例不变、镜头不被无故重置、整套机具不被裁切。
