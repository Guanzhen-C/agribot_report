# 右上角退出按钮验证

所有页面共用一个常驻右上角的“×”按钮，点击调用Application.Quit，与Alt+F4一致。悬停显示“退出软件”。不自动终止ROS仿真，运行仿真时应先点击原有“停止仿真”。

- 界面测试4项全部通过、无跳过：场景往返后按钮保持唯一、实际生成退出字形、悬停提示、屏幕其余区域不被拦截，以及与车辆工具栏、装备关闭按钮、AI助手按钮无重叠。
- 小窗口640×480中使用36×36像素按钮，与装备面板关闭按钮保留间距。
- 原生Linux程序在隔离的1280×720桌面中实际显示“×”，通过真实鼠标点击该按钮后进程退出。systemd结果为success、MainPID为0、ActiveState为inactive。
- 隔离显示只用于避免测试鼠标干扰用户正在编辑的文档；测试的是正常Linux可执行程序，不是编辑器模拟退出。
- 源码测试120项通过，导航算法、模型尺寸、传感器外参及已修复的全屏/落地行为未改。

`targeted_playmode.xml`记录界面回归，`native_exit_button.png`记录原生退出按钮画面。最终运行源码提交为`6dbe35f`。
