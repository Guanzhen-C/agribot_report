# 农机控制台操作手册

## 连接

车端启动 `agribot_mobile_app` 网关后，浏览器访问 `http://<车端IP>:8088`，Android App 也连接这一地址。可以使用手机热点使设备互通，前提是热点未隔离客户端且端口可达。不要求把整套 ROS DDS 图发布到手机。

只启动控制台网关不会自动创建底盘驱动。网关会按选定运行 profile 启动原有 ROS 入口。无设备或无任务时界面应显示无数据/未运行，不代表安装失败。

## 页面

导航：静态地图、当前位置、轨迹、规划、单点/经停点、初始估计、执行取消。地图支持双指缩放。

采集：选择采集任务，启动传感器与录包；相机随既定采集 profile 默认记录。停止采集后等待 recorder 正常收尾再关机或拔盘，不以强制断电代替保存。

地图：显示车端目录中可用地图，实际导航还需地图相关配准/地理参考资源，不是只有一张PNG。

状态：显示传感器有无数据、定位就绪、底盘电压/故障及可选VCU诊断。前端收到消息的频率不用于宣称传感器真实采样率；网页不订阅完整点云/图像以免增加负担。

## 真机启动顺序

1. 确认车辆类型、设备口、地图、标定和底盘协议；先保持 CAN 输出关闭。
2. 启动对应室内/室外 profile，保持静止，检查时间戳、输入新鲜度和定位状态。
3. 有可用 RTK 时提供粗先验；无RTK则尝试可用视觉库，没有库直接跳过；最后支持手动初始位姿。
4. 粗先验进入3D点云两级NDT/GICP精配准，等待通过，不以粗先验显示位置代替定位就绪。
5. 检查地图上车姿、局部障碍、全局路径和轮廓，确认无错位。
6. 人员掌握急停、底盘遥控模式正确后，才按本机安全流程授权低速运动。

这个顺序不保证任意走廊几何都能匹配。重复结构、人体遮挡、错误外参、时间错位和不合理初值都可能失败，需要查看数值和日志。

## 目标与经停点

单目标在当前位置和目标可达的前提下规划。连续经停点通过 Nav2 through-poses Action 提交，车辆通常不在每个中间点停车；停不停仍受路径连续性、目标、障碍、安全门控和控制器能力影响。终点到达判据以真机 profile 为准，不自动继承仿真“半轴距”规则。

取消任务先调用导航取消并由车端执行停止，不仅清空手机画布。网络断开不应停止定位计算，但远程急停不可依赖失联网络；现场物理急停始终保留。

## 配置文件导入

控制台提供运行配置导入及恢复默认入口。导入先校验结构、允许字段和协议，不执行包里任意脚本。没有导入时沿用程序默认配方，不影响既有运行命令。新车型配置仅是离线草案时，应先做实际安装/运动学/底盘验收，不能直接当成通用实车部署包。

## 采集与存储

数据目录由车端配置决定。当前样例使用 `/mnt/agribot_data/bags` 和挂载检查，不是所有电脑都必须建立同名系统目录。先检查目标盘挂载、可写空间，再记录；退出必须等停止完成，确认 metadata 和存储文件关闭。

仅手工编辑二维PGM的噪点不会修改原始3D点云；导航地图YAML中的分辨率和原点不能随意改变，否则地理参考与地图位置不一致。复制地图必须连同对应YAML和运行所需配准资源。

## 可选语义导航

服务器地址由配置提供。用户文字发给服务器检索/模型服务，得到校验过的目的地点和语义限制；车端仍由Nav2规划/控制。没有部署服务器或知识图谱时，该功能不可用，手动导航不应被其阻塞。模型调用凭据放服务器私人配置，不放APK。

## 安全

默认样例 HTTP 绑定 `0.0.0.0:8088` 且未设令牌，仅适合受控本地网络测试。公网/不可信网络需额外认证、加密和网络隔离。不要为了手机连接而把所有防火墙、ROS端口和底盘控制无条件公开。
