# 算法与参数

## 五组组件

| 类别 | 当前Unity选项 | 作用 |
| --- | --- | --- |
| 感知 | STVL、Voxel | 三维障碍标记、清除与成本地图 |
| 额外视觉AI | 关闭、检测、实例分割、姿态估计 | 额外相机叠加，不参与运动控制 |
| 定位 | FAST-LIVO2+RTK、FAST-LIO2、NavSat ESKF、KISS-ICP | 统一输出位姿/里程计 |
| 规划 | Smac Hybrid-A*、NavFn、Theta*、Smac2D、直连 | 全局路径，运动学能力不同 |
| 控制 | MPPI、RPP、DWB | 按当前车辆配置适配跟踪 |

选项以RosSimulationLauncher.cs、unity_sync_and_simulate.sh和compatibility.json为准。组合数量不等于原创算法数量，不表示全部组合已跑完全程。State Lattice等其他原工程配置不表示已加入此Unity菜单。

## 定位

FAST-LIVO2使用相机、激光、IMU，RTK固定解位置提供全局约束。项目保留有界缓冲、接收计算分离、视觉内存管理和局部地图等适配；不能将这些工程改动全部宣称为原创基础算法。

仿真输入来自Gazebo，不是真实设备。模拟GNSS的稳定性不能证明真实场景的卫星信号质量。

空旷、低特征场景可能不适合视觉激光定位。宽地头所有车型仅允许NavSat；葡萄园Car3/4/6、玉米田Car4等有专用定位规则。最终以当前适配目录为准。

## 规划控制

Smac Hybrid-A*考虑姿态和转弯运动学；二维规划和直连不自动满足同等车辆约束。控制器必须使用当前车的尺寸、轴距、转弯半径和速度极限。

仿真关闭周期性全局重规划，但保留初始规划、目标更新和失败恢复重试。局部控制与障碍更新仍运行。

最终位置容差为前后轴距一半，不要求最终航向；中间点顺序仍保留。该规则属于统一配置仿真，不应套用到所有外部系统。

## 参数与证据

车辆配置位于agribot_vehicle_description/config/vehicles和generated/<vehicle_id>/config。运行时还会叠加场景及控制器设置，不应把历史README中的单个数字写成所有车型默认值。

本体轮廓参与导航；机具与机械臂当前不参与导航轮廓和碰撞。代表机具通过后按用户规则确认其他适配机具，不表示逐项重复实测。配置SHA变化后需重新判断旧记录是否有效。
