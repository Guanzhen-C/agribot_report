工具职责：
inspect_bench.py：只读预检与源码指纹。
negative_preflight.py：无硬件输出的输入/身份拒绝性测试。
controller_checks.py --execute：共用受保护工作流启动实体台架，不启动导航任务；
  --checks hitch powertrain parameters可按需选择现有检查，结束时撤销授权并核对真车指纹。
parameter_checks.py：仅通过高层话题请求，实际输出必须经X5/6750/物理CAN，禁止直发执行器话题。
observe_run.py：复用已审阅只读记录器，保存原始CAN、独立真值和代价地图观察。
sensor_audit.py：有限时长的被动订阅及PNG链路RGB哈希核验，不宣称真实传感器硬同步。
probe_diagnostics.py：只读JTAG身份检查，不编程、不擦除、不绕过校验；OpenOCD退出0不等于识别成功。
reset_bound_can.py：仅在会话停止并核对绑定身份后重置单个CAN设备或重绑其驱动，不重置扩展坞。
loopback_bound_can.py：有限的单盒内部回环诊断，finally恢复正常模式；结果不算物理HIL用例通过。
collect_run.py：在任务关闭后，按严格SSH配置归档日志和SHA-256，不复制整个源码或修改真车目录。
