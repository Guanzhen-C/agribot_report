# Unity 操作手册

本页为简版索引；详细操作、示例与常见问题见[完整用户手册](13_user_manual.md)。

## 启动

通过scripts/run_unity.sh进入软件。新进程从新状态开始：未选车、未安装装备、未选场景和算法，不恢复上次聊天。已导入场景和已导出文件仍保留。

## 车辆与装备

1. 在车库选择Car0至Car9，进入单车界面。
2. 打开装备面板，安装雷达、相机、IMU和卫星定位组件，等待动画完成。
3. 安装当前车型允许的机具；不适配的安装按钮不可用。
4. 使用既定默认安装位置，当前不提供任意拖拽式标定。
5. Car0双击车身进入既有修理面板；其他未实现该面板的车不额外提示。

模型展示缩放不等于米制尺寸。导出读取统一测量锚点与当前配置，不能把车库画面大小当作物理参数。

## 场景

内置场景与用户导入场景分开显示。导入支持当前LCC2/K2流程，不保证任意STP、STL或高斯格式都可直接导入。

选择源文件、命名并等待转换验证。成功后才加入场景目录和AI操作上下文。导入场景卡片右上角可删除，确认后删除目录项和对应转换缓存，不删除用户原始扫描文件。运行/准备中不能删除使用中的场景，内置场景不提供该删除入口。

场景名称不自动证明用途、净空、GNSS条件或所有车型可通行。

## 算法

分别选择感知、额外视觉AI、定位、规划和控制。完整选齐并符合车辆/场景限制后启用启动按钮。额外视觉模块主要用于叠加显示，不直接接管车辆运动。

优先使用该车/场景已验证的默认配方。宽地头等场景限定NavSat，部分车型/场景也有专用规则。AI不能绕过本地限制。

## 启动停止

启动仿真会导出当前装配、校验并生成ROS配置、增量编译、启动Gazebo/RViz。首次必须已安装依赖并完成完整仿真构建。失败应查看本次日志，不重复点击堆积任务。

默认不发送目标。按仿真操作文档在RViz选择目标或连续经停点。停止仿真按钮结束本应用管理的进程；仅关RViz窗口不等于所有后台节点退出。

## 导出配置

停止后可以导出配置。保留现有配置契约和原软件的导出入口；外部控制台接收端不属于本仓库。新车型离线草案正常导出不等于真实标定通过。

原Car0完整部署包接口可能要求通过AGRIBOT_HPM_FIRMWARE_ROOT提供外部已构建固件；本仓库不再附带该固件工程，也不承诺无此输入即可生成含固件的部署包。配置草案、ROS配置与仿真不依赖烧录任何板卡。

## AI助手

一个连续会话支持问答和可点击方案。例如：“用小型履带车在葡萄园巡检，搭配机械臂，优先稳定定位。”

上下文包含当前选择、近期对话与操作、备忘，不包含实时相机/点云。方案经本地校验后由用户点击应用；应用不自动启动。

回车发送，Shift+回车换行。关闭面板保留本次会话，跨页面可继续；新对话清聊天和备忘，不擅自改装配或停任务；退出再开软件是新会话。近期消息与备忘有界，不保证无限上下文逐字保留。

list_scenes只读查询实际目录，版本未变时复用。模型思考模式关闭，格式错误最多一次纠正重试，没有自动执行ROS命令工具。
