# 软件概览

## 目标

在三维车库中配置农机和传感器，选择适配的农机具、场景和算法，通过统一车辆契约导出 ROS 配置并启动 Gazebo/RViz，观察算法运行结果。

## 部署

| 组件 | 运行位置 | 职责 |
| --- | --- | --- |
| Unity Linux 应用 | PC 工作站 | 车库、装配、参数、场景、算法、AI、仿真管理、导出 |
| ROS 2 + Gazebo Classic | 同一工作站 | 虚拟传感器、动力学、定位、规划、控制 |
| RViz | 同一图形桌面 | 模型、地图、图像、轨迹、目标与经停点 |
| 配置生成器 | 工作站 Python 环境 | JSON 校验和 URDF/SDF/YAML 生成 |
| 在线模型接口 | 可选网络服务 | AI 文字问答和配置建议，不承担车辆控制 |

没有手机控制台或车端 Web 服务。

## 功能

- Car0 至 Car9 车型目录，按各自运动学和尺寸配置。
- 安装已有传感器模型与适配机具，自动使用预定义位置。
- Car0 修理面板、爆炸图及统一操作按钮。
- 内置场景与用户扫描场景分类管理；导入、删除和转换缓存清理。
- 感知、额外视觉 AI、定位、规划、控制五组组件选择。
- 带连续上下文的 AI 助手和可点击方案。
- 导出当前装配并受管启动/停止 Gazebo/RViz。
- 导出配置文件；对接外部系统不属于本仓库的运行流程。

## 边界

不能自动标定任意新车，不保证所有车型/场景/算法组合均可闭环。机具主要用于安装和运输展示，当前不参与碰撞与导航轮廓，不模拟真实耕作、采摘或土壤产量。

完整车库仍缺少未确认可公开的购买 CAD 衍生资源，参见资源说明。基础仿真和完整 Unity 构建必须区分。
